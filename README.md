# Finance App (Консольное приложение для управления финансами)

Это учебный проект, представляющий собой консольное Java-приложение для ведения личного бюджета. Программа позволяет учитывать доходы и расходы, устанавливать лимиты на категории и отслеживать финансовую статистику.

## Как пользоваться сервисом

1. **Сборка проекта:** Убедитесь, что у вас установлена Java (версия 11 или выше).
2. **Запуск:** Запустите главный класс `Main.java` из вашей IDE (IntelliJ IDEA, Eclipse, VS Code) или через командную строку.
3. **Регистрация/Вход:** При первом запуске вам будет предложено зарегистрировать нового пользователя. Придумайте логин и пароль.
4. **Работа с данными:** После авторизации вам откроется главное меню, где вы сможете добавлять доходы, расходы, менять баланс доступных расходов и просматривать отчёты.
5. **Сохранение:** Все данные автоматически сохраняются в локальный файл (например, `finance_data.txt`) при корректном выходе из программы. 

## Какие команды поддерживаются

После авторизации в главном меню доступны следующие команды (вводятся в виде цифр):

*   `i` — **Добавить расход:** Позволяет ввести сумму, выбрать/создать категорию расхода и записать операцию.
*   `e` — **Добавить доход:** Позволяет ввести сумму и указать категорию дохода (например, Зарплата, Кэшбэк).
*   `v` — **Показать отчет:** Выводит общую статистику (доходы, расходы, баланс), а также детализацию по категориям с информацией о превышении бюджетов.
*   `b` — **Настроить бюджеты:** Позволяет задать или изменить месячный лимит (бюджет) для любой категории расходов.
*   `l` — **Выйти из аккаунта:** Завершает текущую сессию и возвращает в меню авторизации.
*   `q` — **Выход из приложения:** Сохраняет все данные в файл и завершает работу программы.

*(В меню гостя доступны команды: `l` — Вход, `r` — Регистрация, `q` — Выход).*

## Как протестировать код

Вы можете протестировать работу приложения вручную, выполнив следующие шаги-сценарии:

1. **Сценарий "Новый пользователь":**
   * Зарегистрируйте пользователя с логином `test` и паролем `123`.
   * Войдите под этими данными.
   * Выйдите из приложения (`q`). Запустите заново и убедитесь, что ваш аккаунт сохранился (вход по логину/паролю работает).
   
2. **Сценарий "Учет операций":**
   * Добавьте доход (например, 50 000) в категорию "Зарплата".
   * Добавьте расход (например, 1 500) в категорию "Еда".
   * Откройте отчет (`v`). Убедитесь, что общий доход, расход и баланс (48 500) посчитаны верно.

3. **Сценарий "Обработка ошибок и неверного ввода":**
   * **Ошибка ввода:** Введите буквы вместо числа при добавлении суммы. Программа должна вывести ошибку и попросить ввести число заново.
   * **Ошибка регистрации:** Попробуйте зарегистрировать пользователя с логином, который уже существует. Программа должна вывести сообщение о том, что логин занят.
   * **Ошибка авторизации (логин):** Попробуйте войти с несуществующим логином. Программа должна сообщить, что пользователь не найден.
   * **Ошибка авторизации (пароль):** Попробуйте войти с правильным логином, но неправильным паролем. Программа должна вывести ошибку о неверном пароле.
   * **Отрицательная сумма:** Попробуйте добавить расход с суммой `-500`. Программа должна выдать ошибку "Сумма должна быть больше нуля".
